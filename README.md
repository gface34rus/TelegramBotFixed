# Telegram Bot Project

## Описание
Этот проект представляет собой Telegram-бота, который выполняет различные функции, такие как управление задачами и уведомлениями.

## Стек технологий
- Java
- Spring Boot
- Maven

## Установка
1. Склонируйте репозиторий:
   ```bash
   git clone <https://github.com/gface34rus/TelegramBotFixed>
Перейдите в директорию проекта:
cd telegram-bot_new
Установите зависимости с помощью Maven:
mvn install
Запустите приложение:
mvn spring-boot:run
Использование
Для взаимодействия с ботом используйте команды, предусмотренные в его функционале.
Бот будет отвечать на сообщения и выполнять задачи в соответствии с заданной логикой.
Функциональность
Управление задачами
Уведомления
Обработка обновлений от пользователей
